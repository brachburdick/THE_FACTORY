The fix is in place. Here's what changed and why it works:

**Root cause**: macOS kernel routing rules mean a socket bound to a unicast IP (like `169.254.20.47`) only receives *unicast* packets addressed to that IP. Pioneer CDJs send **broadcast** packets (to `255.255.255.255` or the subnet broadcast like `169.254.255.255`) — these are simply never delivered to a unicast-bound socket on macOS.

**The fix — `IP_BOUND_IF` (value 25)**:
- Binds the socket to `""` (i.e. `INADDR_ANY` / `0.0.0.0`) so the kernel *will* deliver broadcasts
- Uses `setsockopt(IPPROTO_IP, IP_BOUND_IF, interface_index)` to restrict reception to only `en16`, so we don't get spurious packets from WiFi or other interfaces
- `socket.if_nametoindex("en16")` resolves the OS interface index automatically — no hardcoded IPs or indices
