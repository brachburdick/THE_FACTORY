## Root Cause

The parser uses the wrong intermediate element name for audio tracks.

| Track type | Actual path | Parser expects |
|---|---|---|
| **MidiTrack** | `MainSequencer/`**`ClipTimeable`**`/ArrangerAutomation/Events/MidiClip` | `ClipTimeable` — correct |

In Ableton Live 12.x (and likely earlier), audio tracks use `<Sample>` instead of `<ClipTimeable>` as the container under `MainSequencer`. The rest of the path (`ArrangerAutomation/Events/AudioClip`) is identical.
