## Key Findings

### 1. Audio Capture — Straightforward
USB audio interface (Scarlett 2i2, ~$170) from the XDJ-AZ's master/booth out → `sounddevice` Python library. ~3-5ms input latency at 48kHz. 512-sample buffers are reliable on macOS. No exotic setup needed.

This is **not** blind source separation (which would be nearly impossible). Because SCUE already knows what tracks are loaded (from beat-link) and has pre-analyzed spectral features, it becomes **informed source separation** — a solved problem.
