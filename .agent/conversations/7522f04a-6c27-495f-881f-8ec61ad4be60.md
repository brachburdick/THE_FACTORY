## TL;DR

**jpoindexter/ableton-mcp** is a 7-week-old, 7-star MIT repo that provides **128 MCP tools** (200+ commands at the Remote Script level) for controlling Ableton Live. It does NOT use AbletonOSC — it ships its own TCP-based Remote Script on port 9877.

**What it actually delivers:**
- Full MIDI note CRUD (read, write, transpose, quantize, humanize)
- Track/clip/scene/device management (create, delete, duplicate, configure)
- Mixer control (volume, pan, sends, returns, master)
- Browser search + instrument/effect loading
- Basic AI helpers (drum patterns in 5 styles, basslines, scale reference)
- Three integration paths: MCP (stdio), REST API (FastAPI), Max4Live device

**What's missing for your use case:**
- **No batch/snapshot** — scanning a 50-track project = 50+ individual tool calls
- **No audio analysis** — can't read waveforms, spectra, or audio content
- **No arrangement clip manipulation** — session view only
