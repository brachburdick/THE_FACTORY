### Decision 2: Embedding API Key

**The situation:** The loop detector needs to call OpenAI's embedding API (`text-embedding-3-small`). That requires an `OPENAI_API_KEY`. The bootstrap `.env.example` doesn't list one.

**Options:**

**(a) Add `OPENAI_API_KEY` to .env — simplest, my recommendation.**
One more env var. The OpenAI embeddings SDK is already spec'd as a dependency. Embeddings are cheap (~$0.02/M tokens). The key is scoped to eval runs just like the Anthropic key. No architectural complexity.

**(b) Make the embedding provider configurable.**
Adds an abstraction layer, a provider interface, and config surface area — all for a single call site. Premature for Phase 1. If we ever want to swap providers, it's a one-file change in `loopDetector.ts` anyway.
